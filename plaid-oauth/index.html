Life Admin

A private, personal application operated by Joe Hahn

Operator

Life Admin is built and run by Joe Hahn, an individual software developer based in Denver, CO. It is not a company or a commercial product.

Purpose

Life Admin is a personal tool for organizing my own household and financial administration. It uses Plaid to connect to my own financial accounts.

Users

I am the only user. The app is not offered to the public, has no sign-up, and does not hold anyone else's data.

Access

The app is self-hosted and reachable only over my private Tailscale network. It is not exposed to the public internet, and I access it only from my own devices.
